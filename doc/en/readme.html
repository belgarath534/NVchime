NVChime 2.1

Customize your NVDA startup and exit sounds with powerful features including schedule mode, random mode, per-event volume control, silent hours, and community sound pack support.

New in 2.1

  • Per-event volume control for startup and exit sounds
  • Silent Hours: set a do-not-disturb window where no sound plays
  • Random mode no longer repeats the same sound twice in a row

Sound Modes

  • Pack sound: choose from the built-in sound pack
  • Custom WAV: use any WAV file from your computer
  • Random: plays a random sound from all available sounds, never the same one twice in a row
  • Schedule: different sounds for morning, afternoon, evening, and night
  • Disabled: no sound

Recommended Setup

Go to NVDA Settings, General, and uncheck "Play sound when starting or exiting NVDA" so only your NVChime sound plays.

How to Use

  1. Open NVDA menu with NVDA+N
  2. Go to Preferences, then Settings
  3. Find the NVChime category
  4. Configure your sounds and hit OK
